# 🏥 Medical Chatbot using Python, NLP & OpenCV

An AI-powered Healthcare Chatbot Website developed using **Python**, **Flask**, **Natural Language Processing (NLP)**, and **OpenCV**.

This project helps users interact with a medical assistant chatbot, analyze symptoms, and upload medical images for basic processing.

---

# 🚀 Features

✅ Symptom-based healthcare chatbot  
✅ NLP-based text understanding  
✅ Medical image upload support  
✅ OpenCV image processing  
✅ Flask web application  
✅ Responsive frontend UI  
✅ Easy to customize and extend

# ⚙️ Installation

## 1️⃣ Clone the Repository

```bash
git clone https://github.com/your-username/medical-chatbot.git
```

## 2️⃣ Navigate to Project Folder

```bash
cd medical-chatbot
```

## 3️⃣ Install Required Libraries

```bash
pip install -r requirements.txt
```

---

# ▶️ Run the Project

```bash
python app.py
```

Open your browser and visit:

```bash
http://127.0.0.1:5000
```

# 💬 Chatbot Capabilities

The chatbot can currently respond to:

- Fever
- Cold
- Cough
- Headache
- Diabetes
- Chest Pain
- Basic medical symptoms

---

# 🖼️ OpenCV Image Upload

Users can upload medical-related images.

The system uses OpenCV to:

- Read uploaded images
- Extract image dimensions
- Process images for future AI model integration
